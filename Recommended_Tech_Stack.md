
# AI Hub – Recommended Tech Stack

## Desktop Application
- Tauri
- React (or Svelte)
- TailwindCSS

## Hub Server
- Node.js
- TypeScript
- Fastify (recommended lightweight API framework)
- ws (WebSocket server)

## Database
- SQLite
- better-sqlite3 (Node library)

## Rust Tools Runner
- Rust
- Tokio
- serde / serde_json
- ripgrep crate
- git2 crate

## Dev Tooling
- pnpm (monorepo manager)
- ESLint
- Prettier
- Turbo or Nx (optional)

## Packaging
- Tauri bundler
